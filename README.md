# Marcus Finlay — Engineering Portfolio

My portfolio built with Next.js, Tailwind CSS, and shadcn/ui, it showcases project case studies, work/education experience, and contact info.

## Getting started

Install dependencies, then run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production build
- `npm run lint` — check code with Biome
- `npm run lint:fix` — check and auto-fix with Biome
- `npm run format` — format code with Biome
